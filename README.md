# とらまめMondまとめ（試作版）

GitHub Pagesでそのまま編集/公開できる静的サイトの試作です。
個人ブログのようなイメージです。
急な思いつきで制作したのでコスト等を考慮してGithub Pagesを選択しました

## 今回の試作のポイント

- 話題ごとの表示
- 質問 → 回答のカード表示
- 関連質問をツリー化
- とらまめさんのMond / X へのリンク
- キーワード検索
- 編集は`data.json` から直接触る
