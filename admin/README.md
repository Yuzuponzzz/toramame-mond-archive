# とらまめMondまとめ — 管理画面プロトタイプ

これは本番用の管理画面UIの試作です。

## 現段階でできること
- 話題の追加・削除・編集
- PICK UP設定
- ルート質問の追加
- 関連質問（子ノード）の追加
- 質問・回答・Mond URL・X URLの編集
- data.jsonの読み込み
- 編集結果をdata.jsonとして書き出し

## 重要
現段階では「書き出したdata.jsonをGitHubへ自動保存」する機能はまだ接続していません。

本番では、
1. 管理者ログイン
2. 管理画面で編集
3. 保存
4. GitHubへ自動コミット
5. GitHub Pagesが自動更新

という流れにします。

GitHubのアクセストークンをHTMLやJavaScriptに直接埋め込む方式は採用しません。
